# Support

Need help with one of our projects? Here is the right place to start.

## Using a project

- Check the project's `README.md` first. It has the installation, setup, and usage details.
- If something is broken, open an issue in the affected repository. Include the version, your platform, the steps to reproduce, and what you expected.
- Where a repository has Discussions enabled, prefer it for open-ended questions and ideas.

## Security issues

Do not report security vulnerabilities in public. Follow [SECURITY.md](SECURITY.md) for private reporting.

## Contributing

If you want to change the code rather than ask a question, read [CONTRIBUTING.md](CONTRIBUTING.md).

## A note on response times

This is a small organization. Issues and questions may sit for a while before someone can answer. Clear, focused reports with reproduction steps are the fastest way to get help.
