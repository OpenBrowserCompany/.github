# Brand assets

The supplied artwork in `assets/branding/originals/` is the source of truth. Those four files are never edited. Everything else in `assets/branding/` is a sized derivative generated by `scripts/generate-assets.py`.

## Asset roles

| Supplied original | Identified as | Use it for |
| --- | --- | --- |
| `company-banner-original.png` | Company banner | The organization profile header and social previews. Contains the mark and the company wordmark. |
| `browser-icon-original.png` | Browser application icon | The browser application only. Do **not** use it as the organization banner. |
| `documentation-mark-light-original.png` | Light documentation mark | Light backgrounds: docs, README panels, print. |
| `watermark-original.png` | Simplified watermark | Small placements, favicons, watermarks, and dark backgrounds. |

## Derivatives

| Path | Size | Purpose |
| --- | --- | --- |
| `company-banner/company-banner-1600x720.png` | 1600 × 720 | Compact derivative of the company banner used as the brand mark in the organization profile README. The full-width marketing banner lives in `originals/` and feeds the social preview. |
| `company-banner/social-preview-1280x640.png` | 1280 × 640 | Repository social preview. Aspect-correct 2:1 crop. |
| `browser-icon/browser-icon-512.png` | 512 × 512 | Application icon, high resolution. |
| `browser-icon/browser-icon-256.png` | 256 × 256 | Application icon, standard resolution. |
| `browser-icon/browser-icon-128.png` | 128 × 128 | Inline use in Markdown. |
| `browser-icon/favicon-32.png` | 32 × 32 | Browser tab icon. |
| `browser-icon/apple-touch-icon-180.png` | 180 × 180 | Touch icon for documentation sites. |
| `documentation/documentation-mark-light-512.png` | 512 px wide | Mark on light backgrounds, transparent. |
| `documentation/documentation-mark-dark-512.png` | 512 px wide | White mark on dark backgrounds, transparent. |
| `watermark/watermark-light-512.png` | 512 px wide | White simplified mark for dark surfaces. |
| `watermark/watermark-light-128.png` | 128 px wide | Small white watermark. |

| `organization-avatar/organization-avatar-512.png` | 512 × 512 | Upload as the GitHub organization avatar. |

The `watermark-dark-*` files are the same supplied geometry recolored from white to near-black. No artwork was redrawn.

## Usage

- Use the banner for wide, horizontal surfaces. Do not crop into the mark or the wordmark.
- Use the browser icon only when referring to the browser application.
- Use the light mark on white or pale surfaces and the white mark on dark surfaces.
- Use the simplified watermark below roughly 160 px; the metallic documentation mark loses detail at very small sizes.
- Keep clear space around the mark. Do not stretch, rotate, recolor, or add effects to the originals.
- To change a size, add a rule to `scripts/generate-assets.py` and regenerate rather than resizing by hand.

## Regenerate

```bash
python3 scripts/generate-assets.py
python3 scripts/check_markdown.py
```
